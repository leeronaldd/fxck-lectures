# Dev Log: 2026-04-07 — V4 Pipeline Complete + Fact-Checking + Textbook RAG

## What Was Built

### V4 Pipeline (full end-to-end, automated)
```
Stage 1 chunks → CI% scoring → Concept Grouper → Generation (Pro + textbook RAG + search grounding)
→ Fact-checker (Flash + textbook + search) → Pro correction loop → Completeness check → Slide insertion → Assembly
```

All steps run with one command:
```bash
python run_stage2.py data/output/final_chunks_v5.json --v4 --no-llm-group \
  --ci data/output/v4_ci_scores.json --screenshots data/output/screenshots.json --preview
```

### New Modules Created
- `src/concept_grouper.py` — merges ~14 chunks into ~8 logical groups, marks skips/expansions
- `src/completeness_checker.py` — grep + slide-term coverage, auto-inserts inline skip-lines
- `src/slide_inserter.py` — post-processing slide references mapped to paragraphs
- `src/fact_checker.py` — textbook RAG + Google Search grounding, Pro correction loop
- `src/json_repair.py` — robust JSON extraction from truncated Flash responses (used by all modules)

### Key System Prompt Iterations (6 total)
1. Base v1 conversational tone restored

### Factual Accuracy Pipeline
- **Generation-time**: Pro has Google Search + textbook chapter as context
- **Post-generation**: Flash verifies entire explanation against textbook + web sources
- **Correction**: Pro surgically rewrites flagged paragraphs
- **Error rate**: 11 errors → 1 remaining across 6 iterations
- Textbook RAG uses hardcoded OpenStax chapter lookup (100% reliable, zero LLM calls for URLs)

### Generalization (works for any medical lecture)
- Removed ALL virology-specific content from system prompts
- Replaced hardcoded SEED_TERMS (84) with Flash extraction (any discipline)
- Replaced hardcoded topic regex with Flash topic naming
- Replaced hardcoded slide term patterns with Flash extraction
- CI% scorer, completeness checker, assembly — all discipline-agnostic
- Only remaining lecture-specific code: deterministic grouper fallback (intentional)

## What Worked
- Textbook RAG during generation prevented the 3 most persistent errors (lytic cycle order, theory bias, terminology confusion)
- `json_repair.py` fixed Flash JSON truncation across entire pipeline (33% → 83% success rate)
- Slide dedup via Flash removed duplicate screenshots
- Inline slide placement (keyword matching) — slides appear next to relevant paragraphs, not dumped in galleries
- CI% recalibration — naming conventions dropped from 32% to 12%, Baltimore stayed at 95%
- The "fix pipeline not output" principle caught 4 instances where I was hand-editing the markdown

## What Failed / Known Issues
- Pro correction loop doesn't always stick (~80% success rate) — 1 error persisted after "correction"
- Flash returns None/truncated responses intermittently — json_repair handles most cases but not all
- Slide insertion via Flash (paragraph mapping) has many JSON parse failures — works via fallback
- DeepSeek V3.2 available on Vertex AI but needs Model Garden enablement — not tested yet
- `group_chunks_deterministic()` is still hardcoded to microbiology (intentional fallback)

## Key Architecture Decisions
- **Textbook wins on facts, professor wins on scope** — textbook for mechanisms/terminology, professor for what to emphasise/skip
- **No lecture-specific rules in system prompt** — general accuracy principles only; textbook RAG catches lecture-specific errors
- **Emojis generated by Pro** (on ### sub-headings), not added by assembly
- **Destructive patcher removed** — Flash was destroying sections when trying to insert terms
- **Slides inserted inline by keyword matching** — zero LLM calls, cap 4 per section
