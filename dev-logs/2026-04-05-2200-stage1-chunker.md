# Dev Log: Stage 1 Chunker — Initial Build

**Date:** 2026-04-05
**Session focus:** Build Stage 1 (transcript chunking) of the lecture-replacement tool

## What Changed

### Built from scratch:
- `src/models.py` — Pydantic models for `Chunk` and `EmphasisSignal`
- `src/chunker.py` — Full Stage 1 pipeline: marker detection, regex splitting, emphasis extraction, prerequisite mapping, multi-concept detection
- `src/config.py` — Vertex AI configuration
- `run_stage1.py` — CLI entry point with `--preview` and `--no-llm` flags
- `CLAUDE.md` — Project guidance file

### Key features:
1. **Token-free chunking** via regex marker detection (slide markers, professor transition phrases)
2. **Contradictory emphasis detection** — catches when professor says "important" + "don't memorize" and correctly marks as HIGH (understand deeply, not skip)
3. **Multi-concept detection** — flags chunks covering multiple enumerated concepts (e.g., 7 Baltimore classes in one chunk)
4. **Gemini Flash sub-chunking** — LLM-based splitting for flagged multi-concept chunks (code written, but Vertex AI access not yet working)
5. **Prerequisite mapping** — tracks which terms each chunk depends on from earlier chunks
6. **Content-derived topic names** — when regex extracts garbled names, falls back to content pattern matching

## Test Results
